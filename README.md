## Personal Expense Tracker

A command-line Python application for recording, searching, and analyzing personal expenses.

## Features

* Add expenses
* View all expenses
* Search expenses by category
* Calculate total expenses
* Generate category-wise expense summary

## Python Concepts Used

* Variables
* Lists
* Dictionaries
* Functions
* `if/elif/else`
* `for` loops
* `while` loops
* String formatting
* Dictionary accumulation


## How to Run

Run `main.py` using Python 3.
